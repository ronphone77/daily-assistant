# Nourish

A mobile-first daily wellness assistant built with Next.js and React. Nourish brings gentle breathing exercises, a 10-minute meditation, short movement routines, meal ideas, lifestyle encouragement, and a simple daily progress tracker into one calm dashboard.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Responsive desktop sidebar and mobile bottom navigation
- Today's plan with interactive completion tracking
- Guided box-breathing player with animated breathing orb
- 10-minute meditation card
- Short movement routine
- Daily meal plan
- Lifestyle tip of the day
- Progress indicator
