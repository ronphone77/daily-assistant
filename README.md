# Nourish

A responsive web-compatible daily wellness assistant built with Next.js and React.

## Web compatibility

Nourish is designed mobile-first and works in modern desktop and mobile browsers, including Android Chrome, iOS Safari, Firefox, and Edge. It includes:

- Responsive layouts for phone, tablet, and desktop
- Desktop sidebar navigation and mobile bottom navigation
- A web app manifest for installation as a standalone app on supported browsers
- Safe-area support for mobile devices with notches and gesture navigation
- Keyboard-friendly buttons and accessible labels

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```
